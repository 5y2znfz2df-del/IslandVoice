# IslandVoice 详细使用手册

**版本：1.1.4**
**项目主页：https://github.com/5y2znfz2df-del/IslandVoice**

IslandVoice 是一个 WinIsland 语音 AI 助手插件：唤醒后用中文说话，大模型回答，
灵动岛显示回复，并用 Edge 神经语音朗读。支持任意 OpenAI 兼容大模型，以及整理桌面、
查天气、打开应用等本地电脑操作。

## 2. 安装

### 2.1 前置条件

- Windows 11 x64（Windows 10 2004+ 也可）
- WinIsland 2.x（ABI v2）
- 一个可用的大模型 API Key（DeepSeek / 硅基流动 / Groq / 本地 Ollama 等）
- 中文对话建议安装 Windows 中文语音识别组件（中文系统默认有）

### 2.2 一键安装（推荐）

1. 完全退出 WinIsland（托盘右键 → 退出）
2. 解压分享包到任意目录
3. 在解压目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\安装.ps1 -WithVosk -WithEdgeTts
```

- `-WithVosk`：下载英文唤醒模型（约 40 MB），用于 `hey siri` 唤醒
- `-WithEdgeTts`：安装 Python 版 Edge 神经语音（晓晓）
- 两个参数都可以省略，省略后仍可用 `Ctrl+Alt+V` 手动说话

4. 启动 WinIsland

### 2.3 手动安装

1. 完全退出 WinIsland
2. 解压 `island-voice-1.1.4.zip`
3. 把内容放到：

```text
%APPDATA%\WinIsland\plugins\island-voice\
```

正确结构：

```text
island-voice\
├─ plugin.yml
├─ island_voice.dll
├─ icon.png
├─ README.md
└─ runtime\
```

不要出现 `island-voice\island-voice\plugin.yml` 这种多套一层。

4. 启动 WinIsland
5. 右键任务栏托盘中的 WinIsland 图标（可能需要点 `^` 展开）

### 2.4 安装 Vosk 唤醒模型（可选）

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\fetch-vosk.ps1 -Language en
```

安装到 `%APPDATA%\WinIsland\IslandVoice\`。装好后可以说 `hey siri` 唤醒；
没装也能用 `Ctrl+Alt+V` 直接说话。

### 2.5 安装 Edge 语音（可选）

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install-edge-tts.ps1
```

需要 Python 3。没装或断网时会自动退回 Windows SAPI 语音。

## 3. 首次配置

1. 右键托盘 → **IslandVoice：配置**
2. 填写：

| 字段 | 说明 |
|---|---|
| 助手名称 | 显示在回复里的名字，默认 IslandVoice |
| 唤醒词 | 默认 `hey siri`（英文 Vosk 模型） |
| API 密钥 | 你的大模型 Key |
| 模型名称 | 如 `deepseek-chat`、`glm-4.5-flash`、`gpt-3.5-turbo` |
| 大模型服务 | 下拉选择预设：DeepSeek / 智谱 GLM-4.5-Flash / 自定义 |
| 大模型地址 | OpenAI 兼容地址，见下表（选预设会自动填） |
| HTTP 代理地址 | 可选，支持 http/https/socks5 |

3. 勾选需要的开关
4. 点 **保存**

> WinIsland 2.0 自带设置页有时会拒绝第三方页面；如果侧边栏看不到，
> 用托盘里的「IslandVoice：配置」即可。

### 3.1 常见大模型地址

| 服务 | 地址 | 模型示例 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com` | `deepseek-chat` |
| 硅基流动 | `https://api.siliconflow.cn/v1` | `Qwen/Qwen2.5-7B-Instruct` |
| Groq | `https://api.groq.com/openai/v1` | `llama-3.1-8b-instant` |
| 本地 Ollama | `http://127.0.0.1:11434/v1` | `qwen2.5:7b` |
| 本地 vLLM | `http://127.0.0.1:8000/v1` | 你的模型名 |

只要接口兼容 `POST /chat/completions`，就可以填进来。

### 3.3 选择模型预设

配置窗口的「大模型服务」下拉框提供：

| 预设 | 自动填入地址 | 自动填入模型 |
|---|---|---|
| DeepSeek（默认） | `https://api.deepseek.com` | `deepseek-chat` |
| 智谱 GLM-4.5-Flash | `https://open.bigmodel.cn/api/paas/v4` | `glm-4.5-flash` |
| 自定义 | 保持你手动填写的值 | 保持你手动填写的值 |

选「智谱 GLM-4.5-Flash」后，把智谱的 API Key 填进「API 密钥」即可。

### 3.2 自定义系统提示词

配置文件里 `system_prompt` 字段可改助手人设。默认提示词要求：
简洁、口语化中文、100 字以内、不要 Markdown，并告诉模型在问天气/整理桌面时
输出 `[ACTION: ...]` 标记。

## 4. 日常使用

### 4.1 唤醒与说话

| 操作 | 方式 |
|---|---|
| 唤醒 | 说 `hey siri`（需 Vosk 模型） |
| 直接说话（跳过唤醒） | `Ctrl+Alt+V` |
| 开始 / 停止监听 | `Ctrl+Alt+J` |
| 打开配置 | 托盘 → IslandVoice：配置 |
| 测试朗读 | 托盘 → IslandVoice：测试朗读 |

**录音规则：**

- 唤醒后不说话：等 **15 秒**才取消
- 说完后停顿：**5 秒**自动结束
- 最长录音：**60 秒**
- 带 200ms 预录和自动增益，减少第一个字被切掉

### 4.2 中文识别

- 中文优先用 **Vosk 中文模型**（`vosk-model-small-cn-0.22`）
- 没有中文模型时用 **Windows 自带 zh-CN 听写（SAPI）** 兜底
- 英文 Windows 需要在
  设置 → 时间和语言 → 语言和区域 → 中文(简体) → 语言选项 → 安装「语音识别」

### 4.3 语音朗读

- 默认用 **Edge 晓晓**（`zh-CN-XiaoxiaoNeural`），需要 Python + `edge-tts`
- 失败自动退回 **Windows SAPI**
- 朗读期间会自动暂停唤醒监听，避免自问自答
- 可以在配置里关闭「朗读 AI 回复」

## 5. 电脑操作（整理桌面 / 天气 / 打开应用）

### 5.1 开启

配置窗口勾选：

> **允许 AI 执行本地电脑操作（整理桌面、查天气等）**

保存后生效。默认关闭，避免误操作。

### 5.2 支持的动作

| 动作 | AI 回复中的标记 | 说明 |
|---|---|---|
| 整理桌面 | `[ACTION: organize_desktop]` | 按扩展名把桌面文件移入子文件夹 |
| 查看天气 | `[ACTION: weather:北京]` | 用 wttr.in 免费接口，无需密钥 |
| 打开应用 | `[ACTION: open_app:计算器]` | 通过 `start` 启动 |
| 打开浏览器 | `[ACTION: open_browser]` | 打开默认浏览器 |
| 打开计算器 | `[ACTION: open_calculator]` | 启动 calc |

### 5.3 怎么触发

直接说：

- 「北京天气怎么样」
- 「帮我整理一下桌面」
- 「打开计算器」

系统提示词已告诉模型在对应场景输出 ACTION 标记；插件解析并执行，
执行结果追加到灵动岛回复里。

> ACTION 标记和「已执行」结果只显示在灵动岛，**不会被朗读**。

### 5.4 限制

- 整理桌面只移动**桌面根目录的文件**，不动子文件夹
- 天气依赖网络（wttr.in）
- 打开应用依赖 Windows `start` 能识别的名称
- 电脑操作是本地执行，不会上传文件

## 6. 灵动岛与 Siri 光球

- 唤醒 / 手动说话 / 朗读回复时，顶部会从灵动岛弹出一颗
  **黑色渐变液态玻璃球**
- 材质：竖向黑灰渐变、边缘彩虹色散、左上高光、底部玻璃亮弧
- **没有中间那条彩虹光条**
- 录音期间一直停留，说完/取消后缩回
- 鼠标可穿透，不挡操作

## 8. 日志与排错

### 8.1 看哪里

- 插件日志：`%APPDATA%\WinIsland\IslandVoice\debug.log`
- WinIsland 日志：`%USERPROFILE%\.winisland\logs\winisland.log`
- 查插件是否加载：搜索 `island-voice`

### 8.2 常见问题

**托盘没有 IslandVoice 菜单**
- 插件没加载：检查 `plugin.yml` 是否直接在 `island-voice\` 下
- 重启 WinIsland
- 看 WinIsland 日志有没有 `Loaded ABI v2 plugin island-voice`

**侧边栏没有设置页**
- 用托盘「IslandVoice：配置」
- 这是 WinIsland 2.0 的第三方设置页兼容问题

**保存不了**
- 请使用 1.1.4 及以上版本；早期版本助手名/模型名为空会拒绝保存
- 现在为空会自动填默认值

**说 hey siri 没反应**
- 先按 `Ctrl+Alt+V` 测试：能识别说明麦克风正常，只是唤醒模型没装
- 运行 `scripts/fetch-vosk.ps1 -Language en`（先退出 WinIsland）
- 或者托盘里停止/开始监听一次

**一直说「没听清」**
- 背景视频/音乐里的 "hey siri" 会误唤醒，测试时先暂停
- 靠近麦克风、减少噪音
- 看日志里的「识别到：xxx」，把 xxx 发出来定位

**中文识别不准**
- 确认系统装了中文语音识别
- 确认 `stt_language=zh`
- 尽量靠近麦克风

**没有声音**
- 运行 `scripts/install-edge-tts.ps1`
- 检查 Windows 默认输出设备/音量
- 断网时会退回 SAPI，仍然应该有声音

**没有配置页 / 保存按钮看不到**
- 1.1.4 已压缩窗口布局，保存按钮应在底部可见
- 如果仍看不到，把窗口拉大或按回车（默认按钮）

**插件导致 WinIsland 卡顿**
- 关闭「朗读 AI 回复」或停止监听
- 查看日志是否有大量重复错误

## 9. 隐私与安全

- 麦克风持续本地监听唤醒词
- 唤醒后的**识别文字**会发送给你配置的大模型服务
- 开启朗读时，**回复文字**会发送给 Microsoft Edge 语音服务
- 默认不会上传原始录音（除非配置在线 STT）
- API Key 明文保存在本机 `store` 目录，**不要分享该目录**
- 插件 DLL 未签名，SmartScreen/杀软可能提示；源码在分享包 `source/`
- 许可证：GPL-3.0-only
